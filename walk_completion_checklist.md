# Walk completion checklist

Tick a walk only after you have actually done it. Leave missed walks unchecked
so you can catch up later, in any order. All 60 walks start unchecked here.

To record a completed walk, change `- [ ]` to `- [x]`. Optionally append a
completion date or notes to that line. You can edit this file locally or edit
and commit it on GitHub after uploading it.

This is separate from the automatic email checklist. The email script never
changes this file, and ticking a walk here does not affect which email is sent.
Emails stop after all 60 walks have been sent, even if some walks here remain
unchecked. Keep your numbered emails to revisit any missed walks.

Full route descriptions: [walking schedule](constituency_every_house_walks_m22_4fp.txt).
